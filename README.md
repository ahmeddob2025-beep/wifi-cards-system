# نظام إدارة كروت الواي فاي

نظام بسيط لإدارة كروت الواي فاي التجارية — يعمل على المتصفح بدون إنترنت (PWA).

## المميزات

- 📊 لوحة تحكم يومية
- 🏪 إدارة نقاط البيع (35-40 نقطة)
- 📥 مخزون المالك
- 📦 صرف كروت للموزع
- 📝 تقرير يومي مع كشف تلقائي عن العجز
- 📱 مبيعات مباشرة
- 📋 كشوفات مفصلة
- 📅 إغلاق شهري
- 💾 نسخة احتياطية

## كيفية الاستخدام

1. افتح الرابط: `https://your-username.github.io/wifi-cards-system/`
2. البيانات تُحفظ تلقائياً في المتصفح
3. للنسخ الاحتياطي: اذهب لـ ⚙️ الإعدادات → 📤 تصدير

## التثبيت على الهاتف (PWA)

### Android (Chrome):
1. افتح الرابط في Chrome
2. اضغط القائمة (⋮) → "تثبيت التطبيق" أو "Add to Home Screen"

### iPhone (Safari):
1. افتح الرابط في Safari
2. اضغط زر المشاركة (□↑) → "Add to Home Screen"

## التقنية

- HTML5 + CSS3 + Vanilla JavaScript
- IndexedDB لتخزين البيانات محلياً
- لا يحتاج خادم خلفي

**ملاحظة:** البيانات تُخزن في المتصفح المحلي فقط. استخدم زر التصدير بانتظام للنسخ الاحتياطي.
